# 공개용으로 일부 수정됨

이 저장소는 실제 업무 분석을 **공개 가능한 범위로 다시 구성한 버전**입니다. 원래 작업과 다른 점은 아래와 같습니다.

## 1. 코드

- 원 분석 코드(Jupyter 노트북과 스크립트)의 로직을 그대로 따르되, 공개용 스크립트로 다시 정리했습니다.
  - 데이터셋마다 따로 있던 로딩 코드를 하나로 합쳤습니다(`src/geo_reader.py`, `configs/datasets.json`).
  - 노트북의 탐색용 셀은 질문 단위의 스크립트로 묶었습니다.
- 모든 경로는 저장소 기준 상대경로입니다.
- 회사 시스템, 칩 플랫폼, 상품과 연결된 코드는 넣지 않았습니다. 칩 측정값 보정, 결과지 판정 로직, 기존 서비스 알고리즘이 여기에 해당합니다.

## 2. 마커와 계수

- README의 모델 수치는 **최종 모델(마커 9개)을 공개 데이터에 적용한 결과**입니다. 최종 패널은 1차 패널(공개 데이터로 고른 8개)에서 칩으로 제작할 수 없는 2개를 빼고 3개를 더한 구성입니다.
- 최종 패널의 마커 구성, 회귀 계수, 절편, 코호트별 보정값은 공개하지 않습니다. 패널은 로컬 전용 파일(`configs/panel.local.txt`, `.gitignore` 대상)로만 코드에 넘깁니다(`--panel`).
- 패널 파일 없이 실행하면 공개 데이터로 고른 1차 패널(8개)로 같은 분석이 진행됩니다. 이 경우 수치는 README와 다릅니다(예: 다른 코호트 평균 오차 5.39년).
- 화면 출력과 결과 파일에서 마커는 `rank_1`, `rank_2`처럼 순위로만 표기합니다. `results/`에는 로컬 확인용으로 CpG ID가 저장되며, 이 폴더는 저장소에 올리지 않습니다.
- 원 분석에서 문헌 마커와 비교하거나 외부에서 제안된 마커를 역검증한 부분은 특정 마커 이름이 핵심이라 제외했습니다.

## 3. 데이터

- 저장소에는 **합성(가짜) 데이터**만 들어 있습니다(`data/synthetic/`). 실제 데이터와 구조만 같고 값은 난수입니다. 그래서 합성 데이터로 나온 수치는 실제 결과와 관계가 없습니다.
- 공개 GEO 데이터는 각자 내려받아 씁니다. 방법은 `docs/datasets.md`에 있습니다.
- 원본 GEO 파일, 개인 단위 β값, 회사 실험 데이터는 저장소에 포함하지 않습니다.

## 4. 원 분석과 달라진 점

| 항목 | 이 저장소 | 원 분석 |
|---|---|---|
| 흡연 판별 AUC 마커 수 | 1, 2, 3, 5, 10, 20, 30개 (같음) | 같음 |
| 전 흡연자 위치(%) | 나이·성별(·질병)을 보정한 값으로 계산 | discovery 코호트는 보정 전 그룹 평균으로 계산 |
| 마커별 ICC 표기 | 노이즈 기여 '순위'만 표시 | 계수와 함께 표시 |
| 평행이동 보정값 | 평가 코호트 50%로 추정, 나머지 50%에서 평가 (평균) | 평가 코호트 전체의 중앙값 (보정 후 미국 MAD 4.35년 → 이 저장소 4.36년) |
| ICC 신뢰구간 | 부트스트랩 1,000회 | pingouin 패키지의 F분포 기반 구간 |
| 생활습관 축 분석의 패널 | discovery 상위 N개 (순위) | 문헌 확인을 거친 특정 마커 5개 |
| 비흡연자 분석 패널 | p값 상위에서 서로 1Mb 이상 떨어진 5곳 (`--manifest`) | 문헌으로 확인한 서로 다른 위치 5곳. 마커 간 상관 +0.199 (이 저장소 +0.140) |
| 대기오염 축 검증 (`exposure_axis_test.py`) | 합성 데이터로만 동작 확인 | 공개 데이터(GSE294810)에 노출값이 없어 실행 불가 → "검증 불가 + 문헌 근거 약함"으로 제외 |

그 밖의 핵심 설계는 원 분석과 같습니다.
- 코호트 간 교차검증
- 50:50 분할 보정
- ICC(2,1)와 MDC = 2.77 × SEM
- 사전에 정한 판단 기준

## 5. README의 수치

- README에 적힌 성능 수치(MAD, R², ICC, SEM, MDC, AUC 등)는 **원 분석에서 공개 GEO 데이터로 얻은 결과**입니다. 회사 상품의 실측 성능이 아닙니다.
- 이 저장소의 합성 데이터로 돌리면 다른 수치가 나옵니다.

## 6. 공개하지 않은 작업

- 칩 측정 데이터 기반 검증과 보정
- 마커 구성 변경 이력
- 결과지 디자인과 상세 판정 기준
- 기존 서비스의 알고리즘 검토

이 작업들의 판단 과정은 `docs/product_decisions.md`에 일반화해서 적었습니다.
